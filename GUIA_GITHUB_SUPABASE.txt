ZAPS · GUÍA RÁPIDA PARA LAU (GitHub Pages + Supabase)

WEB: https://lauravhernandezmm-beep.github.io/ZAPS/

1. Crea proyecto en https://supabase.com/dashboard > New project.
   Guarda la contraseña de la base de datos de manera privada.
2. SQL Editor > New query > pega TODO schema.sql > Run.
   Table Editor > sneakers: debes ver 20 modelos.
   Table Editor > user_sneakers: la tabla debe estar vacía inicialmente.
3. Project Settings > API Keys (o Connect/API Keys, según interfaz):
   copia Project URL y la clave pública publishable/anon.
   NUNCA uses secret/service_role en el navegador o GitHub.
4. Edita config.js:
   supabaseUrl: 'https://TU-PROYECTO.supabase.co'
   supabaseAnonKey: 'TU_CLAVE_PUBLICA'
   siteUrl: 'https://lauravhernandezmm-beep.github.io/ZAPS/'
5. Supabase > Authentication > URL Configuration:
   Site URL: https://lauravhernandezmm-beep.github.io/ZAPS/
   Redirect URLs: añade https://lauravhernandezmm-beep.github.io/ZAPS/
6. Authentication > Sign In / Providers > Email:
   habilita email/contraseña y activa confirmaciones por correo.
7. Authentication > SMTP Settings (o Custom SMTP):
   para correos reales a cualquier usuario, conecta Resend, Brevo o similar.
   Configura host/port/usuario/contraseña del proveedor SOLO en Supabase,
   además del remitente validado; confirma el dominio si el proveedor lo exige.
   El SMTP de prueba de Supabase solo envía a direcciones autorizadas del equipo.
8. Sube archivos actualizados al REPOSITORIO GitHub ZAPS:
   index.html, styles.css, script.js, config.js y carpeta assets/,
   y archivos restantes de la web (NO publiques credenciales privadas).
   GitHub Pages sirve los archivos directamente; no subas solo el ZIP.
9. Prueba: registrar correo NUEVO > confirmar email > iniciar sesión >
   añadir zapatilla > recargar > cerrar sesión > entrar otra vez >
   recuperar contraseña > abrir email > cambiar contraseña.

IMPORTANTE: Cuentas LOCALES anteriores no se migran automáticamente a Supabase.
Nunca subas una contraseña personal de usuario en un archivo ni en GitHub.
