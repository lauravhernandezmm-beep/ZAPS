ZAPS · CONFIGURAR BASE DE DATOS Y RECUPERACIÓN REAL POR EMAIL
===========================================================

ESTA ENTREGA INCLUYE EL CÓDIGO, PERO LA BASE DE DATOS EXTERNA
NO EXISTE HASTA QUE CREES TU PROYECTO DE SUPABASE.

1. EN SUPABASE
   - Entra a https://supabase.com y crea un proyecto.
   - Abre SQL Editor > New query.
   - Copia TODO el contenido de schema.sql y pulsa Run.
   - Esto crea sneakers (20 modelos), user_sneakers y sus permisos RLS.
   - Comprueba en Table Editor que sneakers tiene 20 filas.

2. CONFIGURACIÓN EN ZAPS
   - Abre config.js con VS Code o Bloc de notas.
   - En supabaseUrl pega la Project URL de Supabase.
   - En supabaseAnonKey pega la clave PÚBLICA publishable o anon (Project Settings > API Keys).
   - NUNCA pegues service_role, secret key, contraseña de la BD, SMTP o tokens privados.
   - En siteUrl pega el URL final de tu web, por ejemplo https://zaps-tu-sitio.netlify.app/

3. PUBLICAR EN HTTPS PARA EMAILS Y CUENTAS REALES
   - Entra en https://app.netlify.com y publica la carpeta zaps_web, o usa tu hosting HTTPS.
   - La URL debe ser pública, estable y coincidir con siteUrl.
   - En Supabase > Authentication > URL Configuration configura Site URL con la URL publicada.
   - Agrega esa misma URL a Redirect URLs.
   - En Authentication > Providers > Email habilita email/contraseña.
   - Recomendado: Enable email confirmations.
   - En Authentication > Email Templates > Reset Password conserva la plantilla por defecto con
     su enlace de recuperación. ZAPS reconoce el token de tipo recovery del enlace.
   - Si configuras otra plantilla, el enlace debe dirigir a la web publicada.

4. CORREOS REALES
   - El correo no lo manda HTML ni ChatGPT: lo envía Supabase Auth.
   - El SMTP predeterminado tiene restricciones y solo permite envíos a emails autorizados del equipo.
   - Para enviar a usuarios externos, configura un SMTP propio en Supabase > Authentication > SMTP Settings.
   - Puedes usar un proveedor SMTP (Resend u otro) y verificar su dominio.
   - Ajusta las restricciones/rate limits de correo y comprueba spam.
   - No pongas claves SMTP en config.js: configúralas SOLO en el panel seguro de Supabase.

5. PROBAR FUNCIONES
   - Abre la URL pública de ZAPS, no un archivo file://, para probar el enlace de recuperación.
   - Regístrate con un correo real y confirma la cuenta si Supabase lo solicita.
   - Inicia sesión, añade una zapatilla, edítala, muévela o elimínala.
   - Cierra sesión, inicia sesión desde otro dispositivo: tu colección debe seguir ahí.
   - Haz clic en '¿Has olvidado tu contraseña?', introduce email, revisa la bandeja,
     abre el enlace, establece una nueva contraseña y vuelve a iniciar sesión.

6. MODO DEMO SIN SUPABASE
   - Si config.js sigue vacío, la app funciona localmente, con datos en localStorage.
   - No enviará correos, ni habrá sincronización entre dispositivos.
   - Es un modo de demostración, NO es autenticación adecuada para usuarios reales.

7. IMÁGENES
   - Algunas fotos vienen de webs externas y pueden bloquear el acceso; se usa placeholder si falla.
   - Para máxima fiabilidad sube imágenes a Supabase Storage y cambia la columna imagen_url.
